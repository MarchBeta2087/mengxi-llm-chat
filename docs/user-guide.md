# 梦溪畅谈 — 用户使用手册

| 项目 | 内容 |
| --- | --- |
| 适用对象 | 普通用户（含匿名访问场景，若管理员开启） |
| 文档版本 | v1.0 |
| 相关文档 | [管理员手册](admin-guide.md)、[使用自有密钥测试指南](key-testing-guide.md) |

本手册介绍梦溪畅谈（mengxi-llm-chat）的日常使用：登录、聊天、密钥、插件、外观与隐私。

---

## 1. 登录与注册

1. 打开站点，进入登录页；
2. 首次使用切到 **注册**，填写用户名与密码（用户名 3–64 位，密码 ≥8 位）；
3. 注册成功后自动登录。

**退出登录**：登录后，左侧导航栏底部点击 **🚪 退出登录**；也可在 **设置 → 账户 → 退出登录**。

> 若账号被管理员封禁，登录会提示无权限，请联系管理员。

## 3. 聊天

### 3.1 发起对话

1. 右上角选择**模型**（下拉来自当前可用 Key 池支持的模型）；
2. 在底部输入框输入内容，按 **Enter** 发送（**Shift+Enter** 换行）；
3. 回复以流式（逐字）显示。

### 3.2 会话管理

- **新建会话**：左侧「＋ 新会话」；
- **重命名**：悬停会话条目，点击 **✎**；
- **归档 / 取消归档**：点击 **📦 / ↩**；勾选列表上方「显示归档」可查看已归档会话；
- **删除**：点击 **✕**；
- 会话标题在首轮对话后自动取自你的第一条消息；
- 加密会话在列表显示 🔒 标记。

### 3.3 搜索历史

左侧「搜索会话/消息」输入框，输入关键词后按 **Enter**：匹配标题与（若管理员开启）加密会话内容，点击结果即可跳转该会话。等价接口：

```bash
curl -s "http://<站点>/api/conversations/search?q=量子" -b cookies.txt
```

## 4. 我的 Key（私有密钥）

私有 Key 仅你本人可见可用；系统在调度时**优先使用你的私有 Key**，额度用尽或失败时可按管理员配置**回退到公有池**（届时界面会提示）。

### 4.1 添加

在「我的 Key」页填写：

| 字段 | 说明 |
| --- | --- |
| 展示名 | 便于识别的名称 |
| API Key | 你的上游密钥（提交后仅以 `sk-...xxxx` 脱敏展示） |
| Base URL | 上游地址，如 `https://api.deepseek.com`（必须为 https，除非管理员放开） |
| 模型 | 逗号分隔，可含通配，如 `gpt-4o, claude-*` |
| RPM / RPD | 每分钟/每天请求上限（0 = 不限） |

保存时会自动做 **SSRF 安全校验**：内网、回环、链路本地（如 `169.254.169.254`）会被拒绝。

### 4.2 操作

- **测试**：向上游发起一次真实探测（会计入消耗），显示延迟与状态；
- **停用/启用**：临时下线该 Key；
- **删除**：移除该 Key。

### 4.3 六维限流

除界面上的 RPM/RPD，服务端每条 Key 还支持 RPM/RPH/RPD/TPM/TPH/TPD 六维（Token 维度按上游 `usage` 精确统计）。完整六维可通过接口配置。

---

## 5. 插件

- **全局插件**：管理员添加，对所有用户强制生效，界面显示为锁定（不可关闭）；
- **可选插件**：你可自行启停；开关下方会显示生效来源：
  - `全局强制` / `用户组设定`（此时你无法覆盖）/ `个人设置` / `默认状态`。

> 生效优先级：**全局 > 用户组 > 个人 > 默认**。

---

## 6. 外观定制

点击侧栏 **🎨 外观**（或在 设置 → 外观）：

- 主题色（4 套预设）、深浅模式（浅色/深色/跟随系统）；
- 侧边栏宽度、界面密度、字号。

偏好保存在浏览器本地。

---

## 7. 隐私与安全

- **对话加密**：消息正文在写入数据库前以 AES-256-GCM 加密，按用户独立密钥；
- **密钥安全**：所有 API Key 加密存储，界面与接口仅返回脱敏形式；
- **管理员亦不可见明文**：管理员无法读取你的私有 Key 明文或对话明文；
- **提示**：请勿在对话中主动粘贴敏感凭据；插件返回值被标记为“不可信内容”，不会作为指令执行。

## 8. 限流与配额

| 提示 | 含义 | 建议 |
| --- | --- | --- |
| `429 用户级/ IP 级限流` | 触发用户或 IP 兜底限流 | 稍后重试 |
| `429 今日配额已用完` | 达到你（或所在用户组）的每日 Token 上限 | 次日恢复，或联系管理员 |
| `Key 触发限流/令牌额度耗尽` | 某条 Key 的六维限制 | 添加/启用其它 Key |
| 回退提示 | 私有 Key 不可用，本次改用公共 Key | 无需操作，可在「设置 → 用量」查看 |

## 9. 常见问题

**Q：为什么没有可用模型？**
A：你还没有可用的 Key，且公有池未提供该模型。请在「我的 Key」添加，或联系管理员。

**Q：为什么添加 Key 报错 400/40010？**
A：Base URL 不可解析或命中受保护地址（内网/回环/云元数据），属 SSRF 防护的预期行为。

**Q：退出登录按钮在哪？**
A：左侧导航底部 **🚪 退出登录**，或 设置 → 账户。

**Q：我的对话会被谁看到？**
A：数据库中以密文保存；管理员无读取明文入口。

**Q：如何查看自己的用量？**
A：设置页「用量 / 审计」列出你最近的调用记录（模型、状态、tokens、是否回退）。

## 10. 附录：用户接口速查

> 浏览器中已通过签名 Cookie 登录，curl 示例用 `-b cookies.txt` 携带会话。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` · `/login` · `/logout` | 注册 / 登录 / 退出 |
| GET | `/api/auth/me` | 当前用户 |
| GET/POST | `/api/keys` | 列出 / 新增私有 Key |
| PATCH/DELETE | `/api/keys/{id}` | 编辑 / 删除 |
| POST | `/api/keys/{id}/test` | 连通性测试 |
| GET | `/api/keys/models` | 可用模型列表 |
| GET/POST | `/api/conversations` | 列出 / 新建会话 |
| PATCH/DELETE | `/api/conversations/{id}` | 重命名或归档 / 删除 |
| GET | `/api/conversations/{id}/messages` | 消息（服务端透明解密） |
| GET | `/api/conversations/search?q=` | 搜索 |
| POST | `/api/chat/completions` | 聊天（SSE 流式） |
| GET | `/api/plugins` | 插件及个人生效状态 |
| POST | `/api/plugins/{id}/toggle` | 启停可选插件 |
| GET | `/api/audit` | 我的调用记录 |

示例：新建会话并聊天（SSE）

```bash
curl -s -N -b cookies.txt -X POST http://<站点>/api/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'
```
